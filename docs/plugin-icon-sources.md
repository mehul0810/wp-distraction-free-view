# Companion plugin icon sources

Bundled icons are served locally; opening More Plugins does not fetch third-party images.

- PreviewShare: existing PreviewShare repository `.wordpress-org/icon-256x256.png`.
- Perform: existing Perform repository `.wordpress-org/icon-256x256.jpg`.
- CleanLinks: existing CleanLinks repository `.wordpress-org/icon-256x256.png`.
- ThemeRouter: existing ThemeRouter repository `assets/src/images/icon.svg`.
- OneCaptcha: existing OneCaptcha 1.3.1 proof checkout `assets/img/icon.svg`.
- Klaive: https://plugins.svn.wordpress.org/klaive/assets/icon-256x256.jpg
- MG – Instamojo for GiveWP: official directory fallback https://s.w.org/plugins/geopattern-icon/mg-instamojo-for-give_ffdddc.svg (no custom logo supplied by its listing).

Retrieved/copied 2026-10-04. Brand assets are used only to identify their respective companion plugins. Missing or failed images fall back to the plugin initial; titles remain visible and accessible.

The existing catalog uses `mg-instamojo-for-givewp`, while the directory listing found during asset verification is `mg-instamojo-for-give`. This pre-existing install/link mismatch is outside this visual change and requires a separate catalog correction.
